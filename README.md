# MultiSub Panel

Веб-панель для управления данными MultiSub. Установщик рассчитан на Ubuntu 24.04.

## Установка

Запусти одну команду на сервере:

```bash
curl -fsSL https://raw.githubusercontent.com/plaphase/sub-multi_base/main/install.sh | sudo bash
```

Установщик откроет меню:

1. **Новая панель** — создаст пустую панель с каталогом данных `/var/lib/multisub-panel`.
2. **Существующие данные MultiSub** — найдёт распространённые каталоги данных и предложит выбор, если найдёт несколько. Если каталог не обнаружится, установщик попросит указать его. Исходные файлы сохраняются, для панели создаётся проверенная копия.
3. **Новая панель в другом каталоге** — позволит указать собственный каталог данных.

Далее установщик установит зависимости и Nginx, создаст отдельного системного пользователя, настроит systemd-службу и запустит панель. Он покажет адрес и сгенерирует пароль администратора. Пароль хранится в `/etc/multisub-panel/panel.env` с правами `600`; посмотреть его можно командой:

```bash
sudo grep -E '^PANEL_(USERNAME|PASSWORD)=' /etc/multisub-panel/panel.env
```

## HTTP и HTTPS

Установщик настраивает Nginx на порту 80. HTTP не шифрует логин, пароль или данные панели. Для публичного использования настрой HTTPS и только после этого передавай через панель настоящие учётные данные. Gunicorn слушает только `127.0.0.1:18082`.

## Управление службой

```bash
sudo systemctl status multisub-panel
sudo systemctl restart multisub-panel
sudo journalctl -u multisub-panel -f
```
